# 🌅 The 5 AM Club - Productivity & Routine Tracker

An interactive, feature-rich Progressive Web Application (PWA) inspired by the productivity principles of "The 5 AM Club". This application is built to help users structure their morning routines, track tasks, and optimize their daily habits with high-performance front-end engineering.

🔗 **Live Demo:** [View Live Site](https://mina-web699.github.io/The-5Am-club/)

---

## ✨ Features

- **Progressive Web App (PWA):** Fully equipped with a Service Worker (`sw.js`) and web manifest for complete offline functionality and installability.
- **Audio Notifications:** Integrated sound alerts (`sounds.mp3`) to manage routine transitions and timers seamlessly.
- **Dynamic Daily Management:** Advanced client-side JavaScript architecture to schedule and track habits in real-time.
- **Responsive Layout:** Sleek, modern user interface optimized for production across mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **HTML5 & CSS3:** Modern UI styling layout with highly responsive component design.
- **JavaScript (ES6+):** Dynamic event handling, asynchronous tasks, and application core logic.
- **Service Workers:** Advanced caching strategies to support offline availability.
